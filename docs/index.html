O Problema

A cada ano, o céu desaparece um pouco mais.

Poluição luminosa é o brilho artificial que encobre o céu noturno — afeta ecossistemas, saúde, desperdiça energia e inviabiliza a observação astronômica.

Somado a isso, o ofuscamento viário causado por iluminação pública mal dirigida contribui diretamente para acidentes noturnos.

A Solução

Uma plataforma que escuta a luz das cidades.

O MIRAI reúne dados satelitais e análise inteligente em um dashboard simples, para que gestores possam identificar e priorizar intervenções.

01 · MONITORAR
Dados satelitais

Integração com a base VIIRS da NASA para medição de radiância em todo o território brasileiro.

02 · ANALISAR
Classificação Bortle

Algoritmos classificam áreas por intensidade luminosa e identificam pontos críticos.

03 · AGIR
Dashboard interativo

Mapa nacional com indicadores prontos para apoiar decisões de gestão urbana.
